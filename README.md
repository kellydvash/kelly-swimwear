# Kelly Swimwear

The Kelly Swimwear storefront is built with Next.js App Router, React, and TypeScript.

## Requirements

- Node.js 20.9 or later (scaffolded and verified with Node.js 26.13.0)
- npm 11.20.0 (lockfile included)

## Local development

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run build
```

Tailwind CSS and application features will be added in later implementation milestones.
